# ไฟล์ Node.js สำหรับติดตั้งแบบไม่มีอินเทอร์เน็ต

วางไฟล์ Node.js 22 แบบ binary ไว้ในโฟลเดอร์นี้ ก่อนนำโปรแกรมไปติดตั้งบนเครื่องที่ไม่มีเน็ต

1. ดาวน์โหลดจาก https://nodejs.org/dist/latest-v22.x/
2. เลือกไฟล์ให้ตรงกับผลของคำสั่ง `uname -m` บนเครื่องปลายทาง
   - `x86_64` → `node-v22.xx.x-linux-x64.tar.xz`
   - `aarch64` → `node-v22.xx.x-linux-arm64.tar.xz`
   - `armv7l` → `node-v22.xx.x-linux-armv7l.tar.xz`
3. วางไฟล์ไว้ที่นี่ แล้วรัน `sudo ./install.sh` ตามปกติ

ถ้าเครื่องปลายทางมี Node.js 22.13 ขึ้นไปอยู่แล้ว ไม่ต้องวางไฟล์ใดๆ

> ไฟล์ `.tar.xz` / `.tar.gz` ในโฟลเดอร์นี้ถูกตั้งค่าใน `.gitignore` ไว้ไม่ให้ขึ้น git เพราะมีขนาดใหญ่
